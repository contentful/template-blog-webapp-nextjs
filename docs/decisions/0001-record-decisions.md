# 1. Record decisions in this repository

Date: 2026-10-02

## Status

Accepted

## Context

Contributors and template users need a place to see why notable choices in this template were made.

## Decision

We record notable decisions as short Markdown files in `docs/decisions/`, numbered in order. Each record covers context, decision and consequences.

## Consequences

Dependency upgrades or structural changes that affect template users get a short record here.
